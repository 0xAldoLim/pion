# Stockfish corresponding source

Generated engine files are pinned to the official Stockfish.js v19.0.1 release:
https://github.com/nmrugg/stockfish.js/tree/v19.0.1

Source archive: https://github.com/nmrugg/stockfish.js/archive/refs/tags/v19.0.1.tar.gz

Build instructions and scripts: https://github.com/nmrugg/stockfish.js/blob/v19.0.1/README.md

Pion's exact release URLs and published SHA-256 digests are tracked in scripts/engine-lock.json. Run pnpm assets to reproduce the default assets; pnpm assets:deep for the optional full single-thread pack. COPYING.txt contains the original GPL-3.0 license. Original engine JS copyright headers are preserved without modification.
